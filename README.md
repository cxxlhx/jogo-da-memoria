# Jogo da Memória - DevIcons

## Objetivo

O objetivo do jogo é encontrar todos os 8 pares de ícones iguais no menor número de jogadas (movimentos) possível.

## Regras do Jogo

1. O tabuleiro contém 16 cartas viradas para baixo.
2. Ao clicar em uma carta, ela é revelada.
3. Clique em uma segunda carta para tentar formar um par:
   - Se as cartas forem iguais, elas permanecem viradas para cima.
   - Se as cartas forem diferentes, elas são viradas para baixo novamente após 1 segundo.
4. O jogo termina quando todos os 8 pares forem encontrados.

## Tecnologias Utilizadas

- HTML5
- CSS3 (Flexbox, CSS Grid, Animações 3D)
- JavaScript (Vanilla JS - manipulação do DOM e lógica de estado)
